# Бобохоҷаев Илҳомхоҷа Манонхоҷаевич

Тема: Интернет-магазин: корзина и заказы

Описание: Веб-приложение интернет-магазина. Бэкенд — ASP.NET Core 8 (Web API) + Entity Framework Core (SQLite),
фронтенд — HTML / CSS / JavaScript. Каталог с категориями, поиском и сортировкой; корзина с контролем остатков;
оформление заказа в транзакции со списанием со склада; история заказов покупателя с отменой;
админ-панель для смены статусов заказов и управления товарами.

Проект находится в папке [`ShopApp/`](ShopApp/) — инструкция по запуску в [`ShopApp/README.md`](ShopApp/README.md).
