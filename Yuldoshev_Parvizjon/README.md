## Тема курсовой работы
**«Теплица: контроль температуры и полива»**

## Описание проекта

Greenhouse Control — настольное приложение для мониторинга и управления теплицей.

Программа позволяет:
- Контролировать температуру воздуха.
- Отслеживать влажность почвы.
- Управлять ручным и автоматическим поливом.
- Настраивать допустимые пределы температуры.
- Просматривать историю измерений и поливов.
- Сохранять данные в базе SQLite.

## Используемые технологии

- C#
- .NET 8
- Windows Forms
- SQLite
- Visual Studio 2022
