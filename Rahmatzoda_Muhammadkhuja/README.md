# Академия Вектор — Платформа онлайн-курсов

Полноценное full-stack веб-приложение для проведения онлайн-обучения с кабинетом студента, панелью преподавателя/администратора и сохранением всех данных в локальный JSON-файл (`data/courses-db.json`).

---

## Системные требования

- **Node.js** версии `18.x`, `20.x` или `22.x` (рекомендуется актуальная LTS-версия, например Node.js 22).
- **npm** версии `9.x` или выше (устанавливается автоматически вместе с Node.js).
- Современный браузер (Chrome, Edge, Firefox, Safari).

Проверить установленные версии можно в терминале / командной строке (PowerShell или CMD на Windows):

```bash
node -v
npm -v
```

---

## Пошаговый запуск проекта

1. Откройте папку с проектом в терминале.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер разработки (объединяет Express API и Vite-фронтенд на одном порту):

```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу:

```text
http://localhost:3000
```

### Что делать, если при `npm install` возникает ошибка `ERESOLVE` (на Windows)

Если менеджер пакетов сообщает о конфликте одноранговых зависимостей (`ERESOLVE unable to resolve dependency tree`), выполните установку с флагом совместимости:

```bash
npm install --legacy-peer-deps
```

После завершения установки запустите проект командой `npm run dev`.

## Основные возможности платформы

### 1. Кабинет студента
- **Каталог курсов**: поиск по названию и описанию, фильтрация по категориям (*IT и разработка*, *Дизайн*, *Маркетинг*, *Аналитика*, *Менеджмент*) и уровню сложности.
- **Запись и раздел «Мои курсы»**: мгновенная запись на бесплатные программы, оплата или подача заявки на платные курсы, отображение реального процента прогресса.
- **Плеер обучения**: структура модулей и уроков, чтение материалов, отметка завершения урока с пересчётом прогресса.
- **Интерактивные тесты**: проверка ответов на сервере, начисление баллов и подробные пояснения к каждому вопросу.
- **Домашние задания**: отправка текстового решения и ссылки на проект, отслеживание статусов (*На проверке*, *Принято*, *Нужна доработка*) и комментариев преподавателя.
- **Сертификат об окончании**: открывается при достижении `100%` прогресса по курсу; доступен предпросмотр именного диплома, скачивание в формате **PNG** и печать / сохранение в **PDF**.
- **Расписание вебинаров**: список ближайших онлайн-занятий со ссылками подключения.

### 2. Кабинет преподавателя и администратора
- **Дашборд аналитики**: ключевые метрики (активные студенты, курсы, непроверенные задания, подтверждённые оплаты) и график динамики записей за 6 месяцев.
- **Управление курсами**: создание новых программ, добавление модулей, создание и редактирование уроков, добавление тестов.
- **Проверка домашних заданий**: фильтрация работ по статусу, выставление оценки (0–100), изменение статуса и публикация комментария для студента.
- **Студенты и группы**: создание учебных потоков, прикрепление студентов к группам и сводная таблица успеваемости.
- **Расписание вебинаров с контролем конфликтов**: при попытке назначить два занятия одному преподавателю на пересекающееся время сервер блокирует сохранение и показывает предупреждение с конфликтующим занятием.
- **Учёт оплат и заявок**: подтверждение заявок на обучение с автоматическим открытием доступа студенту.

## Хранение данных и сброс демо-версии

- При первом запуске сервер автоматически создаёт файл `data/courses-db.json` и наполняет его демонстрационными курсами, уроками, студентами, заданиями и вебинарами.
- Все изменения (новые курсы, отметки уроков, оценки ДЗ, записи вебинаров) сохраняются на диске и не пропадают после перезагрузки страницы или перезапуска сервера.
- В верхней панели интерфейса предусмотрена кнопка **«Сбросить демо»**, которая возвращает базу `data/courses-db.json` в исходное состояние.
