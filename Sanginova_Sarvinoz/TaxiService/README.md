# Проект «Служба такси»

Учебное консольное приложение на C# / .NET 8.

## Возможности
- создание заказа с расчётом предварительной стоимости;
- автоматическое назначение первого свободного водителя;
- просмотр заказов и изменение их статуса;
- просмотр и добавление водителей;
- просмотр автомобилей;
- отчёт по выполненным и отменённым заказам;
- сохранение данных в JSON-файл между запусками.

## Расчёт стоимости
Стоимость = 10 сомони за подачу + 3 сомони за каждый километр.

## Запуск
1. Установите .NET 8 SDK.
2. Откройте `TaxiService.sln` в Visual Studio 2022 или откройте терминал в папке проекта.
3. Выполните:
   ```bash
   dotnet restore
   dotnet run --project TaxiService/TaxiService.csproj
   ```

При первом запуске программа автоматически добавляет трёх тестовых водителей.
Файл данных создаётся в каталоге `Data` рядом с исполняемым приложением.
