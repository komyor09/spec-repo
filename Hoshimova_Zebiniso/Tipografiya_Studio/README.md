# Типография — заказы на печать

Настольное приложение для Windows, предназначенное для учёта полиграфических заказов. Позволяет регистрировать клиентов, рассчитывать стоимость печати и отслеживать выполнение заказов. Курсовой проект по объектно-ориентированному программированию на C#.

## Возможности

- **Заказы.** Создание заказа с несколькими позициями, сроком готовности и комментарием. Поиск по номеру или имени клиента, фильтрация по сроку и статусу, отметка просроченных заказов.
- **Статусы.** Принят → В печати → Готов → Выдан. Принятый заказ можно редактировать или отменить с указанием причины. Переходы сохраняются в истории.
- **Клиенты.** Добавление и редактирование карточек, поиск по имени или телефону, просмотр заказов клиента.
- **Тарифы.** 25 начальных тарифов. Поиск, добавление и редактирование услуг, ставок и единиц расчёта.
- **Расчёт стоимости.** Поддержка листовок, брошюр и отдельных услуг. Сумма отображается до сохранения. Изменение тарифа сохраняет прежнюю ставку в оформленной позиции.
- **Удаление.** Заказы, клиенты и тарифы удаляются после подтверждения в отдельном окне. Кнопки доступны после выбора строки. Заказ удаляется вместе с позициями и историей. Клиента можно удалить только при отсутствии связанных заказов, включая отменённые и выданные. Удаление тарифа не меняет стоимость и состав существующих заказов. Служебный тариф скрепления защищён от удаления, его цену можно изменить. Отмена, Escape и закрытие окна подтверждения сохраняют данные.
- **Бланк заказа.** Просмотр документа с данными клиента, составом заказа, формулами расчёта и итоговой суммой.

## Технологии

| Технология | Назначение |
| --- | --- |
| C# и .NET 10 | Модели и бизнес-логика. Целевая платформа — `net10.0-windows`. |
| WPF и XAML | Интерфейс, привязки данных и стили. |
| SQLite и Microsoft.Data.Sqlite 10.0.15 | Локальное хранение клиентов, заказов, истории и тарифов. |

## Запуск

Требуются Windows, .NET 10 SDK и Visual Studio 2026 с компонентом **«Разработка классических приложений .NET»**.

1. Откройте [Tipografiya.slnx](Tipografiya/Tipografiya.slnx) в Visual Studio.
2. Дождитесь восстановления пакетов NuGet.
3. Нажмите **F5** для запуска.

При первом запуске приложение автоматически инициализирует локальную базу SQLite в папке `%LOCALAPPDATA%\Tipografiya`.

## Структура проекта

| Файл в папке `Tipografiya/` | Назначение |
| --- | --- |
| `Tipografiya.slnx`, `Tipografiya.csproj` | Решение Visual Studio, параметры сборки и зависимости. |
| `App.xaml`, `App.xaml.cs` | Точка входа и подключение ресурсов приложения. |
| `MainWindow.xaml`, `MainWindow.xaml.cs` | Разметка и логика разделов «Заказы», «Клиенты» и «Тарифы». |
| `EditorWindows.cs` | Диалоговые формы и проверка ввода. |
| `Models.cs` | Модели клиентов, заказов, позиций и истории. Расчёт стоимости и правила смены статусов. |
| `TariffCatalog.cs` | Модель тарифа, начальный каталог и проверка ставок. |
| `Database.cs` | Инициализация SQLite, чтение и запись данных. |
| `Themes/Studio.xaml` | Стили элементов интерфейса. |
