# Ресторан — столики и заказы

Десктопное приложение на C# и Windows Forms (.NET 8). Интерфейс на русском языке, цены в сомони.

## Запуск на Windows

1. Распакуйте ZIP целиком.
2. Откройте файл `Restaurant.sln` в Visual Studio 2022 версии 17.8 или новее.
3. В Visual Studio Installer должен быть установлен рабочий набор «Разработка классических приложений .NET» и SDK .NET 8.
4. Нажмите **F5** или **Ctrl+F5**.

## Как работать

1. На вкладке «Столики и заказы» выберите свободный столик и нажмите «Открыть заказ».
2. Выберите блюдо из списка, укажите количество порций и нажмите «Добавить блюдо». Чтобы убрать порцию, выделите строку заказа.
3. Подтвердите оплату или отмену. Столик освободится, а заказ останется в истории.
4. На вкладке «Меню» можно добавлять, изменять и удалять блюда. Названия и цены уже добавленных в заказ позиций сохраняются.
5. На вкладке «История заказов» выберите заказ, чтобы увидеть его состав. Выручка суммируется только по оплаченным заказам.

При первом запуске доступны восемь демонстрационных столиков и шесть блюд. Изменения автоматически сохраняются в `%LOCALAPPDATA%\RestaurantApp\restaurant.json`. Программа не требует подключения к базе данных и не использует сторонние пакеты.
