Самадов Музаффарҷон Илхомҷонович

Тема: «ВетМед» — Информационная система ветеринарной клиники

Описание: Веб-приложение для автоматизации работы ветеринарной клиники с разделением ролей (Рабочее место врача и Личный кабинет владельца питомца).

Стек технологий

Frontend: React 19, TypeScript, Tailwind CSS, Vite
Backend: Node.js, Express.js
Хранение данных: локальная файловая БД (data/clinic-db.json, создаётся автоматически при первом запуске — установка отдельной СУБД не требуется)
Требования для запуска

Установленный Node.js версии 20.0 или выше (включает npm) — nodejs.org
Инструкция по запуску

Распакуйте архив с проектом в любую папку и откройте её в терминале (или откройте папку в VS Code и выберите Терминал → Новый терминал).

Установите зависимости:

npm install
(Если при установке на вашей версии npm возникает ошибка конфликта версий пакетов ERESOLVE, выполните npm install --legacy-peer-deps.)

Запустите сервер разработки (Backend + Frontend):

npm run dev
Откройте приложение в браузере:

http://localhost:3000
Примечание: При первом запуске автоматически создаётся файл data/clinic-db.json с демонстрационными данными (8 пациентов, 4 врача, 12 препаратов, записи на приём, анализы, стационар и счета). В интерфейсе есть кнопка «Сбросить базу данных» для возврата к исходному состоянию.

Дополнительные команды
Проверка типов TypeScript:
npm run lint
Сборка production-версии фронтенда:
npm run build
Основные возможности для проверки
В левой боковой панели можно переключаться между двумя ролями:

Рабочее место врача:

Обзор смены — ключевые показатели, очередь приёмов, лист стационара и контроль остатков аптеки.
Пациенты и карты — учёт животных (собаки, кошки, грызуны, птицы, рептилии), электронная история болезни, фиксация осмотров, прививок и выгрузка выписки (.txt).
Запись и расписание — планирование визитов с защитой от наложения слотов у одного врача и сменой статусов приёма.
Стационар и процедуры — контроль пациентов в боксах и отметка выполнения процедур.
Лаборатория и анализы — назначение исследований и ввод результатов.
Аптека и склад — база препаратов с автосписанием при назначении врачом и калькулятором дозировок по весу.
Владельцы и счета — база клиентов и управление оплатами.
Кабинет владельца:

Мои питомцы — паспорта питомцев (микрочип, группа крови, аллергии, диета).
История болезни — просмотр протоколов осмотров и результатов анализов.
Прививки и обработки — календарь вакцинаций и обработок со статусами сроков.
Мои записи — онлайн-запись на приём и отмена визитов.
Назначения и чеки — домашний план приёма лекарств и оплата счетов.
