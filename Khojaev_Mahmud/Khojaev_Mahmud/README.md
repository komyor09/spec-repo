# ParkPay — платная парковка (C#, Windows Forms)

Оконное приложение для учёта парковочных сессий и платежей клиента.
Светлый интерфейс в «парковочных» сине-жёлтых цветах: таблицы сессий и платежей
и карточка «Чек парковки».

## Что реализовано

- три класса: `Client`, `ParkingSession`, `Payment` (плюс вспомогательный класс `Tariff`);
- конструкторы принимают обязательные данные и проверяют их;
- `ParkingSession.Balance` доступен снаружи только для чтения (`private set`);
- `ToString()` переопределён во всех классах (кнопка «Отчёт клиента»);
- в `Main`: клиент с двумя парковочными сессиями (счетами) и тремя платежами;
- задание со звёздочкой: статический счётчик для автоматической генерации `Id` клиента.

## Возможности интерфейса

- список сессий клиента с остатком и статусом, список платежей по выбранной сессии;
- оплата: произвольная сумма или весь остаток, выбор способа оплаты;
- создание новой сессии с автоматическим расчётом по тарифу
  (60 руб./час, первые 15 минут бесплатно, максимум 500 руб./сутки).

## Запуск

Откройте `ParkPay.sln` в Visual Studio 2022 и нажмите `F5`.
Требуется .NET 8 SDK и рабочая нагрузка «Разработка классических приложений .NET».
