# Деканат: студенты и сессия

Консольное приложение на C# (.NET 8).

## Запуск
Установите .NET 8 SDK: https://dotnet.microsoft.com/download

    cd DeanOffice
    dotnet run

Данные хранятся в `data.json` (рядом с exe, в папке bin/Debug/net8.0). При первом запуске создаются тестовые данные.

## Возможности
- студенты: просмотр, добавление, удаление, поиск
- предметы сессии (экзамен / зачёт, по курсам)
- выставление оценок (экзамен 2-5, зачёт 1/0)
- результаты сессии студента, средний балл
- должники, статистика по группам, рейтинг

## Структура
- Models/Models.cs - классы данных
- Services/DeanService.cs - логика
- Services/Storage.cs - сохранение в JSON
- Program.cs - меню
