# Темурзода Мурод Рустам

Тема: Складской учёт (WarehouseAccounting)
Описание: 

Консольное приложение на C# (.NET 8) для учёта товаров на складе: приход, расход, отчёты и журнал движений.

## Возможности

- Добавление товаров трёх типов: электроника, продукты, одежда
- Оформление прихода и расхода (отгрузки) с проверкой остатка
- Отчёт по складу: количество позиций, стоимость, разбивка по категориям
- Журнал всех движений товаров
- Поиск просроченных продуктов

## Запуск

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download).

```bash
cd WarehouseAccounting
dotnet run
```

## Структура проекта

```
WarehouseAccounting/
├── Program.cs                  # Главное меню и ввод/вывод
├── Models/
│   ├── Item.cs                 # Абстрактный базовый класс товара
│   ├── Electronics.cs          # Наследник: электроника
│   ├── Food.cs                 # Наследник: продукты
│   ├── Clothing.cs             # Наследник: одежда
│   └── StockMovement.cs        # Запись журнала движений
├── Services/
│   └── Warehouse.cs            # Логика склада
├── Interfaces/
│   └── IReport.cs              # Интерфейс отчётов
└── Exceptions/
    └── InsufficientStockException.cs  # Собственное исключение
```

## Использованные принципы ООП

| Принцип | Где применён |
|---|---|
| Инкапсуляция | Приватные поля с проверками в `Item.Price`, `Warehouse._items`; `Quantity` меняется только через `Increase` и `Decrease` |
| Наследование | `Electronics`, `Food`, `Clothing` наследуют `Item` |
| Полиморфизм | `Category` и `GetDescription()` переопределены в наследниках; `ToString()` работает для любого товара |
| Абстракция | `Item` — абстрактный класс, нельзя создать «просто товар» |
| Интерфейс | `Warehouse` реализует `IReport` |
| Собственное исключение | `InsufficientStockException` при нехватке товара |

## Возможное развитие
