1. Описание проекта

«Мастерская ремонта техники» — настольное приложение для автоматизации учёта клиентов, технических устройств и заявок на ремонт.

Программа разработана на языке C# с использованием Windows Forms и локальной базы данных SQLite.

2. Основные возможности

Регистрация и поиск клиентов.

Учёт устройств, принимаемых в ремонт.

Создание заявок на ремонт.

Назначение мастеров.

Изменение статусов выполнения заказов.

Учёт запасных частей.

Расчёт стоимости ремонта.

Просмотр статистики и отчётов.

Экспорт данных в CSV.

Сохранение информации в SQLite.

4. Принципы ООП

В проекте используются четыре основных принципа объектно-ориентированного программирования.

Инкапсуляция: управление состоянием объектов через методы с проверкой данных.

Наследование: классы Phone, Laptop и OtherDevice наследуются от базового класса Device.

Полиморфизм: переопределение метода Describe() для различных типов устройств.

Абстракция: абстрактный класс Device определяет общие свойства и поведение устройств.

6. Запуск программы

Требования:

Windows 10 или Windows 11;

.NET 8 SDK;

Visual Studio 2022 версии 17.8 или новее;

доступ к NuGet для восстановления зависимостей при первой сборке.

Порядок запуска:

Скачать репозиторий.

Открыть RepairWorkshop/RepairWorkshop.csproj в Visual Studio.

Восстановить зависимости NuGet.

Собрать проект.

Нажать F5 для запуска приложения.

Альтернативный способ через PowerShell:

cd RepairWorkshop
dotnet restore
dotnet run

При первом запуске программа создаёт необходимые таблицы SQLite.
